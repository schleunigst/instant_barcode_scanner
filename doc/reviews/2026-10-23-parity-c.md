# Review — tranche C (preview geometry and view builders)

Scope: `feat/parity-c-view` (stacked on `feat/parity-ab`): pigeon
`PlatformPreviewMetrics`/`onPreviewMetrics`, `PreviewMetrics`, controller
notifier, `InstantBarcodeScannerView` fit/rotation/mirror/overlay/placeholder,
plugin/activity geometry publishing, example and tests.

## Findings addressed in the branch

- **Rotation was stale when the host handles orientation itself.** Flutter's
  template declares `configChanges`, so an activity re-creation republish is
  not enough. The plugin now registers `ComponentCallbacks` and republishes the
  display transform from `onConfigurationChanged` (plus activity attach for
  re-creation).
- **Two-argument preview callback broke the Android sources** while the
  mechanism signature moved to `(width, height, sensorOrientation)`; plugin and
  the mechanism androidTest were updated together.
- **Missing widget coverage** for the new public surface: tests assert
  placeholder/overlay wiring, `fit`, quarter-turn rotation, mirroring and the
  no-metrics fallback.

## Observations / accepted trade-offs

- Rotation/mirroring are applied in Dart (`RotatedBox` + `Transform` +
  `FittedBox`) rather than through a native texture transform. Works for the
  full-frame stream this plugin requests; a camera with its own crop transform
  would need native handling. Documented in the parity matrix.
- Front-camera preview is mirrored to match every consumer camera app; there
  is no opt-out yet (not requested in tranche C).
- `PreviewMetrics` is re-sent on any configuration change, including font
  scale. The controller notifier suppresses rebuilds when the value is equal.
- `BoxFit.none`/`scaleDown` are accepted; `FittedBox` centers them. No clamping
  because the widget may be larger than the preview intentionally.
- Geometry is only asserted on device (integration test waits for non-null
  metrics with integral rotation); the actual upright/mirrored pixels still
  need a human visual check on both facings and a rotated activity.

## Verification

- `flutter analyze` clean, `flutter test` 84 passing, debug APK builds,
  androidTest compiles.
